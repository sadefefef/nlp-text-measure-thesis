# NLP 多维文本测度与图书评论评分预测

> 本科毕业论文模拟稿配套代码仓库
> 题目：**基于多维 NLP 文本测度的图书评论评分预测研究——以豆瓣读书为例**

本仓库包含论文全文、可复现的中文文本测度实现、语料、实验脚本与全部实验结果，
用于支撑论文第 3–5 章的论述。

## 快速复现

```bash
python -m pip install jieba numpy pandas scipy scikit-learn matplotlib snownlp

python code/corpus_builder.py --n 3000     # 1. 生成语料
python code/experiment.py                  # 2. 抽取测度 + 跑全部实验 + 出图
# 或一键：
python code/run_all.py
```

全部实验固定随机种子 `20260517`，在 CPU 上约 1.5 分钟完成。

## 测度体系一览

| 维度 | 测度 | 含义 |
|---|---|---|
| 情感维度 SE | SE1 情感极性均值 | 句级情感得分的均值，∈[-1,1] |
| | SE2 情感强度 | 单位句长的情感得分绝对值 |
| | SE3 情感波动 | 句级情感得分的标准差 |
| | SE4 正负倾向度 | (正句数−负句数)/情感句总数 |
| | SE5 情感一致性 | 主导极性句占比 |
| 语义维度 SM | SM1 主题集中度 | 评价侧面分布的最大份额 |
| | SM2 信息含量 | 内容词平均 IDF |
| | SM3 领域相关度 | 与类别质心 TF-IDF 的余弦相似度 |
| | SM4 语义离散度 | 1 − 句向量平均余弦相似度 |
| 语言复杂度 LC | LC1 词汇丰富度 | 类符数/√形符数（长度归一化 TTR） |
| | LC2 平均句长 | 句均字数 |
| | LC3 词汇难度 | 内容词 −log₁₀(相对词频) 的均值 |
| | LC4 长词率 | ≥3 字内容词占比 |
| | LC5 修饰密度 | 形容词/副词占比 |
| 信息结构 IS | IS1 文本长度 | ln(1+字数) |
| | IS2 句数 | 句子条数 |
| | IS3 标点多样性 | 标点分布的信息熵 |
| | IS4 标点密度 | 标点数/字数 |
| | IS5 信息密度 | 内容词/总词 |
| | IS6 具体性 | 数词、量词占比 |

## 主要结论

见 `results/summary.json` 与论文第 5、6 章。核心结论：

1. 20 项测度中 19 项与评分显著相关（α=0.05），语义维度测度的判别力最强。
2. 全测度岭回归把 MAE 从常数基线的 1.075 降到 0.567，随机森林进一步降到 0.532。
3. 三分类（差评/中评/好评）宏平均 F1 达 0.78；中评类最难判别，符合「评分极性模糊区」的一般规律。
4. 消融实验显示语义维度是信息贡献最大的维度；情感维度贡献最小，说明领域词典测度存在提升空间。
5. K-means 分群后簇内「情感—评分」关联显著减弱，提示测度空间自身已吸收评分的主要方差。

## 语料说明与局限

`data/reviews.csv` 为**控制变量语料**（DBR-3K），由图书评论领域的真实语用单元组合生成，
评分标签为生成过程真值。它适合验证测度体系与建模流程的有效性、保证实验可复现，
但语言多样性弱于真实平台语料，绝对性能不能直接外推到线上场景。
`experiment.py` 可直接改读任意「text + rating」两列的 CSV 以在真实数据上复现。
